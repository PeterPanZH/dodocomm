# 嘟嘟通讯 · 使用说明

适用系统：Android 8+（含 ColorOS / LineageOS 等定制系统）。

---

## 一、安装

1. 从 [GitHub Releases](https://github.com/PeterPanZH/dodocomm/releases/latest) 下载最新 `DodoComm-<版本>.apk`，传到手机（数据线 / 网盘 / adb 均可）。
   - 电脑 adb 安装：`adb install -r DodoComm-<版本>.apk`
2. 点击 APK 安装；如提示「禁止安装未知来源应用」，请在系统设置中允许当前文件管理器/浏览器安装应用。

## 二、配置 Bark

1. iPhone 上安装 Bark，打开后复制首页的 **Device Key**（一长串字母数字）。
2. 获取 Bark 服务器地址：
   - 使用官方服务：`https://api.day.app`
   - 自建服务：例如 `http://10.0.0.8:8080`（家里局域网）或你的公网域名。自建服务器地址不用带 `/push` 后缀，App 会自动补齐。
3. 安卓 App →「设置 → 推送 → 推送通道 → Bark」：
   - 服务器地址：填上一步的地址；
   - Device Key：粘贴复制到的 Key；
   - 点「测试连接」。iPhone 应立即收到「嘟嘟通讯 测试」推送。
4. 回到「首页」，打开顶部「正在转发」开关。

> 标题模板支持变量：`{sender}` 发件号码、`{sim}` SIM 标签、`{time}` 时间、`{device}` 手机名称、`{number}` 收信号码；点模板下方标签即可插入。
>
> 「常驻通知栏」可关闭：关闭后不显示常驻通知，改用短信广播 + 定时补发（后台可靠性会下降）。
>
> 「后台隐藏」开启后，离开 App 即从最近任务中移除；桌面图标、通知和转发不受影响。

## 三、权限（首次使用必须完成）

| 权限 | 用途 | 不授予的后果 |
| --- | --- | --- |
| 短信（RECEIVE_SMS） | 接收新短信并转发 | 无法转发 |
| 通知（POST_NOTIFICATIONS） | 显示常驻转发通知 | 前台服务通知不可见，后台可靠性下降 |
| 电话状态（可选） | 显示双卡卡槽/运营商标签 | 不影响转发，只是不显示 SIM 标签 |

App 首页有「配置检查」卡片，逐项点击即可跳到对应设置。

## 四、后台保活设置

### ColorOS 等定制系统

1. **允许自启动**：设置 → 应用 → 应用自启动 →「嘟嘟通讯」→ 允许。
   （App 内「保活向导 → 打开自启动设置」可直接跳转。）
2. **电池不限制**：设置 → 电池 → 应用耗电管理 →「嘟嘟通讯」→ 允许完全后台行为 / 取消限制。
3. **锁定最近任务**：从屏幕底部上滑进入最近任务，把「嘟嘟通讯」卡片下拉锁定（小锁图标）。
4. **保留通知**：允许通知，不要清理常驻通知。
5. 如开启「省电模式 / 睡眠待机优化」，请把本应用排除。

### LineageOS 等类原生 Android

1. **电池优化**：设置 → 应用 → 嘟嘟通讯 → 电池 → 选择「不受限制」，或使用 App 内「申请忽略电池优化」。
2. **通知**：允许通知，保留常驻通知。
3. **后台限制**：设置 → 应用 → 嘟嘟通讯 → 限制后台活动 → 确认关闭。
4. LineageOS 等类原生系统没有厂商自启动管理器，无需额外设置；如安装了第三方省电/内核调优模块，请把本应用列入白名单。

> 说明：所有设置均使用 Android 官方提供的开关，不需要 root，不使用后台音频等非常规保活手段。

## 五、隐私与数据（1.7.0 新增）

- **应用锁**：设置 → 隐私与安全 → 应用锁，设置 6 位 PIN；可启用指纹/面容解锁（需硬件支持），并选择离开 App 后立即/1 分钟/5 分钟重新上锁。忘记 PIN 只能清除应用数据。
- **记录搜索/筛选**：记录页右上角搜索按钮；漏斗按钮可按发送者、内容关键词、时间范围筛选。
- **验证码**：记录卡片会标出验证码；详情页可一键复制。设置 → 推送 → 推送内容 → 自动复制可选「仅复制验证码」。
- **导出记录**：设置 → 数据 → 导出记录，支持 CSV/JSON、时间范围、脱敏。
- **备份配置**：设置 → 数据 → 备份配置/恢复配置；导出需设置至少 8 位密码，文件同时绑定本机密钥，同机可用指纹快速恢复，换机用密码恢复。备份不含历史记录与应用锁 PIN。
- **记录保留**：设置 → 数据，选择保留期限/条数或立即清理。
- **通知暂停**：长按/展开常驻通知，点「暂停30分」；或点「恢复转发」提前恢复。
- **标题/消息体模板**：设置 → 推送 → 推送内容。标题默认 `{device} · {sender}`；消息体默认 `{body}\n\n{datetime} · {sim} · {number}`，会在短信原文下方附上时间、SIM 和收信号码。可用变量：`{body}`、`{device}`、`{sender}`、`{sim}`、`{number}`、`{time}`、`{date}`、`{datetime}`。消息体模板不含 `{body}` 时，原文仍会自动保留。

## 六、多通道推送与路由（1.8.0）

- **推送通道**：设置 → 推送 → 推送通道。支持 Bark、ntfy、Telegram、Pushover、Email(SMTP)；每个通道可单独启停和测试。
- **同时发送**：所有已启用且配置完整的通道都会收到短信；至少保留一个。
- **路由规则**：设置 → 推送 → 路由规则。可按发送者、内容关键词、SIM 槽位、时间段匹配，并选择目标通道；默认首条命中停止，可开启继续匹配或回退默认。
- **重试策略**：设置 → 后台与可靠性。可设置最大重试次数、首退避时间、仅 Wi-Fi 重试、最大重试时长。
- Email 使用邮箱的 SMTP 授权码，不是登录密码；常见端口 587（STARTTLS）或 465（SSL）。

## 七、语言切换

设置 → 外观 → 语言，可选「跟随系统 / 简体中文 / English / 日本語」，切换后立即生效。1.7.1 起完整支持三语界面。

## 八、应用内更新

- 设置页底部「检查更新」可手动检查 GitHub Releases。
- 「自动检查更新」默认开启：成功时每 24 小时检查一次；失败按 1h → 2h → 4h → … → 24h 退避，不会频繁联网。
- 发现新版本后下载 APK，App 会校验 SHA-256、大小和签名，再交给系统安装器；若提示「未知来源应用」，请允许本 App 安装未知应用后重试。
- 更新为覆盖安装，不静默安装；请保持同一签名。

## 九、转发规则与样式

- **标题模板**：默认「来自 {sender}」。可用变量：`{sender}` 发送者、`{sim}` 卡槽/运营商、`{time}` 时间、`{device}` 手机名称、`{number}` 收信号码。例如「{device} · {sender} · {sim}」或「{sender} → {number}」。
- **推送样式**：分组、铃声、级别（即时/时效性/静默/重要）、图标、点击打开 URL、归档、自动复制、角标。
- **过滤规则**：
  - 发送者白名单：非空时**只转发**列表内的号码；
  - 发送者黑名单：不转发列表内的号码；
  - 关键词黑名单：短信内容包含任一关键词时不转发；
  - 号码匹配会自动忽略 +86、空格、短横线，并支持后缀匹配。
- 被规则拦下的短信会以「已过滤」状态出现在记录页（可在设置中关闭记录）。

## 十、常见问题

**Q：测试推送失败怎么办？**
A：先确认手机能打开 Bark 服务器地址（浏览器访问 `你的地址/ping` 应返回 `{"code":200}`）。自建局域网地址需要手机和服务器在同一网络；公网地址请确认端口开放与 https 证书。App 会显示具体错误原因。

**Q：短信收到了但 iPhone 没收到？**
A：打开 App「记录」页看该条记录状态：若为「失败」会显示原因；若为「已过滤」请检查过滤规则；若显示「已送达」但 iPhone 无通知，请检查 Bark App 的通知权限/分组/静音设置。

**Q：App 被系统杀掉了还能转发吗？**
A：短信到达会通过系统广播唤醒应用，通常可以正常转发；前台服务负责常驻与失败补发。但若系统把应用「强行停止」，任何第三方应用都无法自动恢复，需要手动打开一次 App。请按第四节的保活设置降低被冻结/杀掉的概率。

**Q：重启手机后，常驻通知没有自动回来？**
A：Android 16 起，系统可能限制「开机后立刻启动前台服务」，ColorOS 的省电策略也可能拦截。此时 App 会发一条「短信转发服务未自动恢复」的通知，点按打开 App 即可恢复常驻转发。期间短信接收和即时转发由系统短信广播保障，不受影响。若希望开机即恢复，请确认第三节的「自启动」「电池不限制」已开启。

**Q：支持自建 Bark 的 http 吗？**
A：支持，App 已允许明文 HTTP（用于局域网自建服务）。公网建议使用 https。

**Q：会读取我以前的短信或联系人吗？**
A：不会。App 只接收新到的短信广播，不申请读取历史短信/联系人权限；数据只发送到你填写的 Bark 服务器，本地最多保留 500 条记录，可一键清空。

**Q：双卡如何区分？**
A：授予「电话状态」权限后，可显示「SIM 2 · 中国移动」；标题模板中用 `{sim}` 即可带入推送标题，用 `{number}` 可尝试带入收信号码（部分运营商/SIM 不提供本机号码，此时会自动省略）。
