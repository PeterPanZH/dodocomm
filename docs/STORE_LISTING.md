## 长描述

DodoComm 是给「安卓收短信、其他设备收通知」场景准备的小工具，灵感来自原神「嘟嘟通讯」活动。

主要能力：
- 收到短信自动向 Bark / ntfy / Telegram / Pushover / Email 推送
- 多通道可同时启用，支持单通道测试
- 路由规则：按发送者、关键词、SIM 槽位、时间段选择目标通道
- 标题/正文模板、验证码自动识别与复制
- 失败自动重试，可限制次数、间隔、仅 Wi-Fi
- 本地记录正文与发送者使用 Android Keystore 加密
- 应用锁、加密配置备份、CSV/JSON 导出
- 运行诊断、后台设置向导、桌面小组件
- 无广告、无账号、无第三方统计；短信只发送到用户自己配置的通道

## 关键词

## 截图顺序

1. 首页（状态 + 今日统计）
2. 记录（搜索/筛选/验证码）
3. 推送通道
4. 运行诊断
5. 后台设置向导
6. 设置 → 外观（深色/语言）

## 隐私摘要

- 不收集、不上传任何数据；没有分析 SDK
- 短信内容只发送到用户配置的推送通道或 SMTP 服务器
- 本地记录正文/发送者用本机 Keystore 密钥加密；密钥不随备份导出
- 配置备份需用户设置密码，支持本机密钥或密码恢复
- 崩溃日志只保存在本机，最多 10 条，不自动上传
